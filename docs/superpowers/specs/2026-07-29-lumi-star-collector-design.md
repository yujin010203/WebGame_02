# 루미(Lumi) — 별빛을 모으는 아기 유령 · 설계 문서

작성일: 2026-07-29

## 1. 개요

HTML5 Canvas + Vanilla JavaScript로 만드는 탑다운뷰 2D 감성 미니게임. 모바일 세로 비율(9:16 근사) 우선.

**스토리**: 새벽, 모두가 잠든 밤. 작은 아기 유령 '루미(Lumi)'는 아침이 오기 전까지 밤하늘에서 떨어진 조각난 별빛을 모아 자신만의 작은 우주를 채운다.

**플레이어**: 동글동글한 하얀 파스텔 톤 유령. 이동 시 은은한 꼬리 잔상(파티클 트레일).

**분위기**: 힐링되면서도 몽환적인, 몽글몽글한 네온 아케이드 스타일. 배경은 딥 블루 밤하늘(`#0F172A`) + 떠다니는 먼지 입자.

## 2. 확정된 결정 사항

- **Firebase**: 프로젝트 미생성 상태. 콘솔 생성 단계별 가이드를 제공하고, 코드는 `firebaseConfig`만 채우면 동작하도록 준비 (Firestore 사용).
- **점수 공식**: 별×100 + 피버 파괴×200 + 생존시간 보너스(초당 +10).
- **코드 구조**: ES 모듈 파일 분리.
- **사운드**: `assets/audio/` 경로 훅 구성. 사용자가 mp3를 넣으면 재생, 없으면 무음(no-op).

## 3. 아키텍처

**패턴**: 엔티티 배열 + 씬 상태머신 (채택). ECS·God-object는 이 규모에서 과설계/유지보수 문제로 배제.

- 각 오브젝트(별/장애물/파티클)를 배열에 담고 매 프레임 `update(dt)` / `draw(ctx)` 순회.
- 씬 전환: `START → INTRO → PLAYING → GAMEOVER` 상태값으로 제어.
- 게임 루프: `requestAnimationFrame` + `deltaTime` 보정으로 기기별 프레임 편차 대응.

**렌더링**:
- 고정 내부 해상도 **450×800**(9:16 근사)로 그린 뒤 CSS로 화면에 맞춰 스케일(letterbox).
- 모든 그래픽은 Canvas 절차적 드로잉 (외부 이미지 없음).
- `devicePixelRatio` 스케일로 Retina 대응.

**입력**:
- `pointermove` 하나로 마우스·터치 통합.
- 포인터 좌표를 목표점으로 두고 유령이 `lerp`(감속 추적)으로 따라감.

**UI 분리**: 게임 화면은 Canvas, 시작/게임오버 오버레이(닉네임 입력폼·Top10 랭킹표)는 DOM 오버레이로 처리.

## 4. 모듈 구조

```
index.html
css/style.css
js/
  main.js          # 부트스트랩, 캔버스/리사이즈, 게임 루프, 씬 상태머신
  input.js         # 포인터/터치 → 목표 좌표
  player.js        # 루미: lerp 이동, HP연동 비주얼(크기·glow·alpha·깜빡임), 꼬리 파티클
  stars.js         # 노란 별 스폰/획득
  items.js         # 특수아이템: 달빛 쉴드, 별똥별 파동
  obstacles.js     # 레이저(예고선), 유도 먼지 Orb, 소나기 빗방울
  fever.js         # 피버 게이지·슈퍼노바 무적 모드
  particles.js     # 공용 파티클 시스템(꼬리·폭발·먼지 배경)
  hud.js           # HP바, 점수, 별 개수, 피버 게이지, 화면흔들림
  difficulty.js    # 시간 경과에 따른 스폰주기/속도 스케일
  audio.js         # assets/audio/ 로드·재생 (파일 없으면 no-op)
  firebase.js      # Firestore 랭킹: 점수 제출(최고점만), Top10 조회
  ui.js            # 시작/인트로/게임오버 DOM 오버레이 제어
  config.js        # 모든 밸런스 상수 (HP, 점수, 스폰율 등 한곳에)
```

**원칙**: 각 모듈은 단일 책임 + 명확한 인터페이스. 밸런스 수치는 전부 `config.js`에 모아 튜닝을 쉽게.

## 5. 게임 메커니즘 (밸런스 수치 — `config.js`)

| 항목 | 값 |
|---|---|
| HP 최대 / 시작 | 100 / 100 |
| 피격 데미지 | −15, 무적 1초, 화면흔들림 |
| 별 획득 | +100점, HP+10(최대 100), 피버게이지 +1 |
| 생존 보너스 | 초당 +10점 (게임오버 시 합산) |
| 피버 발동 | 별 게이지 10 도달 → 5초 슈퍼노바, 게이지 리셋 |
| 피버 중 장애물 파괴 | +200점, 무적 유지 |
| 유령 크기 | HP 100%→크기 100%, HP에 선형 비례, 최저 50% |
| 후광/투명도 | HP 비율에 따라 shadowBlur·globalAlpha 감소 |
| 위험 연출 | HP ≤ 20% 시 깜빡임 |
| 달빛 쉴드 | 희귀 스폰, 1회 피격 방어막 |
| 별똥별 파동 | 희귀 스폰, 화면 내 장애물 전멸 |

### HP ↔ 유령 비주얼 연동
- **100%**: 큰 크기, 풍성한 꼬리 파티클, 커다란 후광(shadowBlur).
- **감소 시**: 크기 소폭 감소(최저 50%), 후광 밝기·범위 감소, 약간 투명(globalAlpha).
- **≤20% 위험**: 깜빡이는 위험 연출.

### 장애물 3종
- **빛줄기(Laser)**: 붉은 반투명 예고선 1초 반짝임 → 가로/세로/대각선 레이저 발사.
- **유도 먼지(Orb)**: 유령을 향해 천천히 접근, 5초 추적 후 소멸.
- **소나기 빗방울**: 위에서 아래로 빠르게 낙하하는 빛 입자.

### 난이도 상승
- 경과 시간에 비례해 스폰 주기 감소 + 이동 속도 증가.
- `difficulty.js`에서 `elapsedSec → 배율` 곡선으로 관리 (완만한 증가).

### 피버 타임 (Supernova)
- 별 게이지 10 도달 시 발동, 5초간 무적.
- 유령이 무지개빛 네온으로 강하게 빛남.
- 장애물과 충돌 시 파괴 + 보너스 +200점.

## 6. 화면 흐름 & 데이터 플로우

```
START(타이틀·조작법·닉네임 입력·시작 버튼)
  → INTRO(세계관 2~3초 오버레이)
  → PLAYING(게임 루프)
  → GAMEOVER(HP 0): 버틴 시간(초), 최종 점수, 모은 별 개수 + Top10 랭킹
```

- 게임 상태(HP/점수/별/시간)는 중앙 상태 객체로 관리.
- 게임오버 시 점수 계산 → Firebase 제출 → Top10 조회 → 오버레이 표시.

## 7. Firebase (Firestore) 스키마

```
컬렉션: scores
문서ID: 닉네임(정규화)     ← 문서ID=닉네임으로 "닉네임당 최고점만" 보장
필드: { nickname, score, stars, survivedSec, createdAt }
제출 로직: 트랜잭션으로 기존 score < 신규 score 일 때만 덮어쓰기
랭킹 조회: orderBy(score, desc) limit(10)
```

- 보안규칙은 개발용 오픈으로 시작, 배포 시 좁히는 가이드 함께 제공.
- `firebase.js`는 config 미설정/네트워크 실패 시 **랭킹만 비활성화하고 게임은 정상 동작**.

## 8. 에러 처리 & 견고성

- **Graceful degradation**: Firebase·오디오 파일이 없어도 게임은 끊김 없이 동작.
- **네트워크 실패**: 랭킹 제출/조회 실패 시 "랭킹을 불러올 수 없어요" 표시, 게임 진행엔 영향 없음.
- **닉네임 검증**: 빈 값·공백·과도한 길이 방어, 정규화 후 저장.

## 9. 테스트 전략

- **순수 로직 단위 테스트** (브라우저 불필요): 점수 계산, 난이도 곡선(시간→배율), HP→비주얼 매핑(크기/alpha/blur), 최고점 판정 로직.
- **수동 플레이 검증 체크리스트**: 렌더링, 충돌 판정, 입력 반응성, 씬 전환, 모바일 터치, 랭킹 표시.

## 10. 스코프 밖 (YAGNI)

- 다국어 지원, 설정 화면, 로그인/계정, 리더보드 페이징, 리플레이, 도전과제 등은 이번 범위 제외.
- BGM/효과음 파일 제작은 제외(경로 훅만 제공, 사용자가 mp3 배치).
